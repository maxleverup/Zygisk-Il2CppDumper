FEATURE COMPARISON:
───────────────────────────────────────────────────────────────

OLD VERSION (Original):
  ❌ Hardcoded package name: "com.game.packagename"
  ❌ Hardcoded library: "libil2cpp.so" only
  ❌ Must modify code to change target
  ❌ Rebuild for each new package
  ✓ Simple but inflexible

NEW VERSION (Modified):
  ✅ Dynamic package name from config file
  ✅ Support ANY library (libMod.so, libUnity.so, etc.)
  ✅ No code changes needed (file-based config)
  ✅ One build, multiple targets
  ✅ User-friendly & flexible

───────────────────────────────────────────────────────────────

KEY CHANGES SUMMARY:
───────────────────────────────────────────────────────────────

1. NEW FILE: config.h
   - Reads /data/local/tmp/il2cpp_dumper_config.txt
   - Parses PACKAGE_NAME and TARGET_LIBRARY
   - Returns Config struct with both values

2. MODIFIED: main.cpp
   - Includes config.h
   - Calls ReadConfig() in onLoad()
   - Uses config.packageName instead of GamePackageName
   - Passes target_library to hack_prepare()

3. MODIFIED: hack.cpp
   - hack_start() now takes target_library parameter
   - xdl_open(target_library) instead of "libil2cpp.so"
   - hack_prepare() passes target_library through
   - NativeBridgeLoad() receives target_library

4. MODIFIED: hack.h
   - Updated function signature to include target_library

───────────────────────────────────────────────────────────────

EXAMPLE USAGE:
───────────────────────────────────────────────────────────────

CREATE CONFIG:
  adb shell "cat > /data/local/tmp/il2cpp_dumper_config.txt << 'EOF'
  PACKAGE_NAME=com.goo.lagme
  TARGET_LIBRARY=libMod.so
  EOF"

TRIGGER:
  adb shell am start -n com.goo.lagme/.MainActivity

MONITOR:
  adb logcat | grep "detect game\|loaded\|dump done"

RETRIEVE:
  adb pull /data/data/com.goo.lagme/files/dump.cs
